# 从财报原文到一张可复算的图：Open ETF Agent 入门实战

<LearningPathNav />

看见图上写着「25%」，你会怎么核对？回到报告，找到两个数，再看它们是不是同一个指标、同一种单位、相隔同样的期间。只给一张漂亮的图，或把整份报告链接放在文末，这几步仍得靠读者猜。

这一篇把核对过程走一遍。我们用一份**合成的发行人公告**代替实时财报，练习的是同一类工作：从公告页面找到附件，认出表格中的两个数，计算相对变化，再从图表返回原始出处。所有数据都是教学样例。

## 先跑起来：不用申请模型密钥

在 Linux 上准备 Node.js 26.x（最低 26.8.1）、npm 和可执行的 `/usr/bin/python3`。该固定版本的受控公式解释器使用这个 Python 路径。安装依赖需要访问 npm；安装后的两个练习不访问真实网站或模型服务。

```bash
git clone --branch v1.0.5 --depth 1 https://github.com/hpoenixf/open-etf-agent.git
cd open-etf-agent
npm ci --ignore-scripts --no-audit --no-fund
node --test test/local-gui-web-pdf-chart-chain.test.mjs
```

你会看到两条用例：一条把网页、原始表格单元格、公式和图表连起来；另一条证明没有可用表格时依然能回读有引用的正文。两条都应通过，不应显示跳过。这是[固定版本的可执行练习](https://github.com/hpoenixf/open-etf-agent/blob/v1.0.5/test/local-gui-web-pdf-chart-chain.test.mjs)：测试用预设的模型动作驱动本机运行时，实际执行 PDF 解析、计算、保存和回读。命令输出测试结果，不会打开浏览器或留下网页截图。

## 从公告入口走到数字真正所在的位置

公告页面上的「原始文件」链接是线索。练习沿该链接取得含文字层的 PDF，再读取文件的第 1 个物理页。「物理页」说的是 PDF 文件里的页序，不一定等于封面、正文或者页脚上印的数字。

先读表头，再取值。练习的 `PERFORMANCE (%)` 表里，`NAV` 行和 `Benchmark` 行紧邻。只抽取两个数字，容易拿错行；保留表名、行名、列名、单位和来源，就能确认计算消费的是下面这两个单元格。

| 表格行 | 2025（%） | 2026（%） |
| --- | ---: | ---: |
| NAV | 0.32 | 0.40 |
| Benchmark（不用作本次公式输入） | 1.10 | 1.20 |

两列是不同年份；这里算的是 `NAV` 行所报百分比的相对变化，不能解读成基金赚了 25%。如果问题问的是「增加了多少个百分点」，答案应是 **0.08 个百分点**，而不是 25%。同样的两个数，口径一换，答案就变了。

## 用引用传递输入，不要让图表从正文猜数字

计算的核心是 `(0.40 / 0.32 - 1) × 100 = 25%`。在练习里，模型交给受控公式的不是从回答抄出来的两段字符串，而是两条已读取单元格的引用。运行时解析这两条引用、核对输入单位，然后执行 `growth(nav)`。图表使用该次公式的结果；只有第二个点有增长率，第一年没有比较基期，留空而不是填 0。

为什么不直接让模型给前端一组数？临时画一张没有复核要求的示意图，这样做更简单。可一旦数字要写进报告，「数来自哪」和「怎么算的」就都要可交代。这里把两者分开：模型选指标与公式，运行时读取原值并算出结果，前端只呈现数据。受控公式能验证计算过程，不能代替人判断选的指标和口径是否合理。

如果有人把引用写成一个并未读过的单元格，练习会看到公式无法使用该来源，而不会给它猜一个值。这正是保留来源身份的用处：它不只是输出里的装饰。

## 最后倒着验收一遍

从 **25%** 倒着问：它对应哪次计算？计算用了哪两个输入？两条原始出处能否回到同一份 PDF 的第 1 个物理页，并分清 2025 和 2026 两列？练习分别检查图表的来源链接与保存的单元格记录。随后关闭并重开运行时，读取原正文、来源和图表，核对它们没有变化，也没有重新下载 PDF 或重新请求模型。这样复核的是**当时的材料**，不是后来重新抓到的版本。

再试一份无可用表格的文件。练习中的另一份 PDF 仍有可引用的文字，说明基金在七月更换了基准，却没有可用数表。正确交付是给出这句话和对应页码，说明为什么没有图。若连可读文字也没有，就应该说明没有取得足够证据；不要把缺失变成结论。

下一次给 Agent 接财报或基金定期报告，可以沿这条线验收：**点得到原文，找得到原值，按同口径复算；做不到时，保留有证据的部分。**
