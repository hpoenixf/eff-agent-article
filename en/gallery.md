# Architecture Gallery

**Start with the [six-layer architecture guide](/en/articles/017-prompt-to-answer-six-layer-panorama)** to understand the Native Agent Loop, evidence, publication and durable human interaction; then use this owner gallery to locate individual capabilities. The [localized six-layer diagram](../visuals/en/017-prompt-to-answer-six-layer-panorama/v2-native-loop-en.svg) presents the same story visually.

The [architecture gallery](/gallery) maps system capability owners, dependencies and article entry points. The interactive diagram currently uses Chinese labels; this English page is a guided entry, not a claim that the source diagram has been translated.

The gallery now identifies **41 capability owners**, including A35 Content Security and Trust. Its dedicated [English case study](/en/articles/agent-content-trust-prompt-injection) explains why source data must not silently become system instructions. The visual labels remain Chinese and are not presented as a fully translated gallery.

### Updated scope — October 24, 2026

The original capability count remains 41. The current update adds bounded status notes for concurrency, asynchronous delivery, Reviewable result attachments, personal subagent profiles, optional market-calendar evidence, and a unified evaluation question catalog. It does **not** add A36 or proposed human-interaction workflows as fully accepted owners.

The code paths are not the same as end-to-end acceptance: financial research completion, authenticated account and PostgreSQL recovery, real calendar-source usage, model quality and deployment retain separate evidence requirements. Open a related owner's detail in the Chinese interactive map for the narrower source-level status; this page remains a guide rather than a fully translated diagram.

The gallery's capability owners are not additional architectural principles. Use the [core principles and engineering methods](/en/principles) for general decisions and the [writing roadmap](/en/roadmap) for forthcoming coverage.

For textual introductions, start with [architecture thinking](/en/thinking) or the [complete catalog](/en/catalog).
