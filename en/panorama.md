# Panorama Series

<small>TAG · PANORAMA SERIES · CROSS-CATEGORY SELECTION</small>

How does an Agent system deliver a complex task to its user? Start with maps of the system, financial responsibilities and architectural judgment. Then understand **what a model needs to know at each step and how the system keeps that information useful**. Continue through five connected questions: how to observe work, evaluate outcomes, inspect evidence, coordinate specialists and continue research across time.

Each essay stands alone, with concrete scenarios, end-to-end relationships, trade-offs and diagrams. Context governance has two complementary essays: Principles connects goals, evidence, boundaries, memory, discovery and progress; Practice explains system prompts, the memory lifecycle, exact readback and sustained-task mechanics. Existing observability, evaluation, citation and Subagent essays retain their original URLs. The long-horizon panorama connects compaction, recovery, continuation and delivery through one lifecycle.

## Start with Your Current Problem

New to agents? Begin with [Agents in 15 Minutes](/en/articles/agent-in-15-minutes), then use the six-layer panorama to examine a complete request. For financial products, start with the financial-agent map to distinguish research, data, business authorization and actual effects. For design choices, begin with the nine judgments behind one report.

For context design, [Context Governance · Principles](/en/articles/agent-context-governance-principles) explains the task view a model needs. [Context Governance · Practice](/en/articles/agent-context-governance-actions) follows first-request assembly, system prompts, memory recall and effects, exact readback, user corrections, compaction and handoffs. Each is independently readable; deeper module essays are optional extensions.

When building or improving a research system, follow one task through the other five engineering panoramas: **long-horizon research** explains continuing work; **Subagents** examines delegation and handoff; **citations** connects conclusions to original evidence; **observability** reveals actual handoffs; **evaluation** judges whether a change delivers the value required. You can also read any one directly without finishing the others first.
