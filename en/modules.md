# Module Deep Dives

Follow the mechanisms that take an agent from an input through research, tool execution, stored results, memory and final publication. Translations are published separately and retain the original article identity.

**A41 cross-Run context:** [Why an Agent Cannot Simply Summarize Conversation History](/en/articles/agent-conversation-history-compaction-source-boundaries) explains exact completed pairs, source hashes, immutable assistant-only summaries, and bounded projection into later Runs, separately from Main checkpoint compaction.

**A40 user feedback:** [When a User Dislikes an Answer, Is It Automatic Learning?](/en/articles/agent-feedback-facts-not-automatic-learning) distinguishes verified answer identity, Scope, idempotent persistence, exact readback, and outstanding browser/PostgreSQL qualification.

**New custom-expert case study:** [A Custom Expert Should Be More Than a Prompt Field](/en/articles/agent-custom-expert-from-prompt-to-recovery) follows account revisions, frozen Run identities, Child method inputs, History attribution, and lessons from real integration defects. It also compares the design with Octop's persistent expert instances.

**A08 deep dive:** [Durable control events](/en/articles/agent-control-events-durable-owner-adoption) separates original business receipts, claim/fence validity and delivery acknowledgment.

**A30 deep dive:** [Provider capacity leases after HTTP 200](/en/articles/agent-provider-admission-capacity-lease) covers shared endpoint queues, streaming terminals and unknown occupancy.

**A10 deep dive:** [Why a Unified Model API Still Needs Shared Admission](/en/articles/agent-provider-architecture-and-admission) now also explains A32 catalog/route eligibility. The separate A30 essay owns the full shared-capacity lifecycle.

**A35 deep dive:** [Prompt Injection Is More Than Malicious Text](/en/articles/agent-content-trust-prompt-injection) explains producer-bound instruction identity, final SDK projection checks, and local effect authority. The evidence is structural; real-model resistance remains unqualified.

**New mechanism deep dives:** [Durable human response adoption](/en/articles/agent-durable-human-interaction-response-adoption) explains HIO request/response identity and the actual research consumer; [temporal semantics](/en/articles/agent-temporal-semantics-market-calendar) distinguishes user days, exchange sessions and data-as-of facts; [Shadow Credits](/en/articles/agent-personal-credits-shadow-accounting) tracks physical model attempts with explicit unknown usage. Their local implementation evidence is not production qualification.

**Six stable reading keys:** L1 input and triggers; L2 identity, sessions and context; L3 Agent decisions and execution; L4 tools and domain capabilities; L5 publication and delivery; L6 user interface. The [six-layer panorama](/en/articles/017-prompt-to-answer-six-layer-panorama-v3) supplies the responsibility map. Placement does not prohibit cross-layer participation; system overviews and cross-layer observation stay in [architecture](/en/thinking), not an invented seventh layer.
